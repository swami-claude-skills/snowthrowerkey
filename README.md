# Snow Thrower Push Key Challenge

Live site: https://swami-claude-skills.github.io/snowthrowerkey/

Two Claude-built parametric generators for a snow thrower push key, plus the run that compares them. Each page is one self-contained HTML file (3D viewer, parameters, export), so nothing needs to be installed.

| Page | Path |
|---|---|
| Launch page | [`/`](https://swami-claude-skills.github.io/snowthrowerkey/) |
| Fable 5.2 key generator | [`/fable/`](https://swami-claude-skills.github.io/snowthrowerkey/fable/) |
| Opus 5.5 key generator | [`/opus/`](https://swami-claude-skills.github.io/snowthrowerkey/opus/) |
| Opus vs Fable comparison | [`/usage-compare/`](https://swami-claude-skills.github.io/snowthrowerkey/usage-compare/) |

## Exporting a model

Open a generator, set the parameters, pick a format (STL, 3MF with part colours, quad OBJ, parameters CSV, settings JSON, or everything as a zip) and press **export file**. The file downloads straight from your browser; nothing is uploaded anywhere.

## Updating

Replace the `index.html` in the matching folder and push to `main`. GitHub Pages republishes within a minute or two.
